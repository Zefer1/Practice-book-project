# Bookshelf App

Practice project to re-learn full-stack development.

## Stack

- **Backend** — Node.js, Express, TypeScript
- **Frontend** — React, TypeScript, Tailwind CSS, Vite

## What it does

A simple bookshelf tracker. Add books, update their reading status, delete them.

## Running locally

**Backend**
```bash
cd bookshelf-api
npm run compile
npm start
```

**Frontend**
```bash
cd bookshelf-client
npm run dev
```

Backend runs on `http://localhost:3000`, frontend on `http://localhost:5173`.
